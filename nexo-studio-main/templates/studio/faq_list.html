Como funciona

  1. O visitante envia uma pergunta no chatbot do site.
  2. A API recebe JSON e procura correspondências nas perguntas e palavras-chave ativas deste negócio.
  3. A interação e a resposta são registradas no banco de dados.
  4. Se não houver correspondência, o chatbot informa que não encontrou uma resposta e direciona para o contato comercial.

Privacidade: não solicite dados sensíveis no chat. Em produção, defina política de retenção, limite de requisições e controles de abuso.
